# Vídeo Humà — pasta de trabalho

| Pasta | Conteúdo |
|---|---|
| `originais/` | Gravações originais, preservadas. Nunca editar aqui. |
| `assets/` | Fotos, logos, banners, áudios de apoio. |
| `projeto/` | Projeto Remotion (código em `src/`, materiais usados pela edição em `public/`). |
| `entregas/` | Arquivos finais exportados (MP4). |
| `registros/` | Controle de custos e consumo (Cap. 3 e 4). |
| `.claude/skills/` | Skills oficiais do Remotion (remotion-dev/skills). |

Briefing: `projeto/briefing.md`.

## Abrir a prévia

```bash
cd projeto
npm run dev
```

Composição de teste: `PrimeiroProjeto` — 1080×1920, 30 fps, 5 s, texto "Meu primeiro projeto".
Ao copiar um material para `projeto/public/`, manter o original em `originais/` ou `assets/`.
